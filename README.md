# Project 5: Enhanced Task Management System

## Description

This project is an enhanced version of the Task Management System with persistent storage capabilities using File I/O operations.

In the previous version, tasks were stored only in memory using ArrayList. When the application closed, all data was lost. To overcome this limitation, file persistence was implemented.

## Additional Features

* Persistent task storage
* Automatic file creation and management
* Data retrieval after application restart
* Error handling for file operations

## Technologies Used

* BufferedReader
* BufferedWriter
* FileReader
* FileWriter

## Implementation Details

Custom JSON serialization and deserialization techniques were implemented to convert task objects into text format and reconstruct them from stored data.

## Learning Outcome

This project provided practical experience with file handling, data persistence, serialization concepts, and advanced Java programming techniques.
